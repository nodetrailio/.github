# Contributing

The Nodetrail checker engine is private.

The product is the read-only checker at [nodetrail.io](https://nodetrail.io) and [@nodetrailbot](https://t.me/nodetrailbot).

## Reports

- Security issues and impersonators: [nodetrail.io/security](https://nodetrail.io/security). Do not open a public GitHub issue, and never include a seed phrase or private key.
- Brand or typo notes on a public repo in this org can be opened as an issue on that repo, as long as they are not security reports.

We do not accept unsolicited code for the checker engine.
