# Security Policy

**On-chain sight, security tight.**

Nodetrail is a read-only onchain checker. We never message you first. We never ask for a seed phrase, private keys, a wallet connect, or a signature.

Anyone who messages you first, or who asks for a seed phrase, private keys, or a wallet connect, is not Nodetrail.

## How to report

Report impersonators and security issues at [nodetrail.io/security](https://nodetrail.io/security).

Use only the contact routes already on that page. In [@nodetrailbot](https://t.me/nodetrailbot), you can send `/support` with a screenshot and the fake username or URL.

**Do not** open a public GitHub issue for a security report.

**Never** include a seed phrase, private keys, or recovery words in a report, a ticket, a DM, or a form.
